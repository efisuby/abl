# Spec Delta

## Purpose

Задаёт базовые настройки приложения: тему оформления, язык интерфейса, разрешение на уведомления и общий экран настроек.

## ADDED Requirements

### Requirement: Тема оформления

Пользователь MUST иметь возможность выбрать светлую, тёмную или системную тему. По умолчанию используется системная тема, смена применяется сразу без перезапуска.

#### Scenario: Смена темы

- **WHEN** пользователь выбирает тёмную тему
- **THEN** интерфейс сразу переключается на тёмное оформление

#### Scenario: Системная тема

- **WHEN** выбрана системная тема, а в системе включён тёмный режим
- **THEN** приложение отображается в тёмном оформлении

### Requirement: Локализация

Интерфейс MUST поддерживать русский и английский языки. По умолчанию используется язык системы, при отсутствии перевода — русский.

#### Scenario: Английская система

- **WHEN** язык устройства — английский
- **THEN** интерфейс отображается на английском

### Requirement: Разрешение на уведомления

На Android 13 и выше приложение MUST запрашивать разрешение на уведомления перед первым фоновым воспроизведением. При отказе воспроизведение MUST работать, а уведомление с управлением не показываться.

#### Scenario: Отказ в разрешении

- **WHEN** пользователь отклоняет запрос разрешения на уведомления
- **THEN** воспроизведение запускается, уведомление не появляется, приложение не падает

### Requirement: Экран настроек

Приложение MUST предоставлять экран настроек, где собраны тема, язык, режим «только Wi-Fi», объём скачанного с возможностью очистки, состояние синхронизации и выход из аккаунта.

#### Scenario: Очистка скачанного

- **WHEN** пользователь нажимает «Удалить все загрузки» и подтверждает
- **THEN** аудиофайлы удаляются с устройства, книги остаются в библиотеке со статусом «в облаке»
