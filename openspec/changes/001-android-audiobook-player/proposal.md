# Изменение 001: Базовая структура Android-приложения для аудиокниг

## Описание
Создание базовой структуры Android-приложения для прослушивания аудиокниг с использованием Kotlin и Clean Architecture.

## Контекст
Разрабатывается мобильное приложение для прослушивания аудиокниг на Android платформе. Приложение должно поддерживать воспроизведение аудио, управление плеером и библиотеку аудиокниг.

## Архитектура
Приложение будет использовать Clean Architecture с следующими слоями:
- **Domain**: Бизнес-логика, сущности, репозитории (Kotlin)
- **Data**: Дatasources, DAO, Repository implementations (Room, Network)
- **Presentation**: UI компоненты, ViewModel, StateFlow

## Компоненты

### 1. Аудио-движок (Audio Engine)
- Интеграция с ExoPlayer для воспроизведения аудио
- Поддержка управления воспроизведением (play/pause/seek)
- Обработка ошибок и буферизации

### 2. Библиотека аудиокниг (Library)
- Отображение списка аудиокниг
- Детальный просмотр книги (обложка, автор, главы)
- Поиск и фильтрация книг

### 3. Плеер UI (Player)
- Экран плеера с контролами воспроизведения
- Прогресс бар и таймеры
- Настройки громкости и скорости воспроизведения
- Режимы повтора и перемешивания

### 4. Синхронизация с Яндекс Диск (Sync)
- Сохранение прогресса в Room локально
- Интеграция с Яндекс Диск API для облачного хранения
- Хранение JSON файлов с метаданными книг и прогрессом
- Восстановление позиции после перезапуска приложения
- Синхронизация между устройствами через Яндекс Диск

## Инварианты

### I1: Аудио воспроизведение должно быть плавным
Приложение должно поддерживать воспроизведение с минимальными задержками и артефактами.

### I2: Прогресс должен сохраняться автоматически
Позиция воспроизведения должна сохраняться каждые 5 секунд или при паузе/перезапуске.

### I3: Интерфейс должен реагировать на изменения состояния
UI компоненты должны обновляться при изменении состояния плеера (play/pause, seek, ошибка).
